# 🪢 gohang

> A sleek, terminal-based Hangman game built in Go. Test your vocabulary right from your command line.

---

## ✨ Features

* **Classic Word-Guessing Gameplay:** Guess hidden words letter by letter before running out of attempts.
* **Dynamic ASCII Gallows:** Renders progressive terminal ASCII art for every incorrect guess.
* **Input Validation:** Prevents duplicate guesses, invalid non-alphabet characters, and empty inputs.
* **Zero External Dependencies:** Built entirely with the standard Go library (`fmt`, `bufio`, `os`, `strings`).

---

## 🛠️ Prerequisites

* **Go (v1.18 or higher)** installed on your machine.
